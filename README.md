# 📝 Simple To‑Do App

A lightweight To‑Do application built with **HTML, CSS, and JavaScript**.  
This project demonstrates **CRUD operations (Create, Read, Update, Delete)**, task filtering, and persistent storage using **localStorage**.

---

## 🚀 Features
- ➕ Add new tasks
- ✅ Mark tasks as completed (green checkbox)
- ❌ Delete tasks
- 🔍 Filter tasks by **All / Active / Completed**
- 💾 Persistent storage with **localStorage**
